ISSUE #1: Infinite Recursion in Template Fallback
────────────────────────────────────────────────
Problem: 
  emit_install_sh() 
    → render_template() 
    → _render_format_fallback() [when Jinja2 unavailable]
    → emit_install_sh() [LOOP!]

Root Cause:
  - emit_install_sh() always calls render_template()
  - render_template() calls _render_format_fallback() when Jinja2 unavailable
  - _render_format_fallback() then calls emit_install_sh() again for "install.sh"

Solution:
  1. Added _emit_install_sh_direct() function for fallback generation
  2. Modified emit_install_sh() to:
     - Check if Jinja2 is available
     - Check if templates/ directory exists
     - Call _emit_install_sh_direct() if either missing
     - Only call render_template() when templates available
  3. Breaks recursion cycle at the source

Result:
  ✅ Recursion fixed
  ✅ Fallback mode works without Jinja2
  ✅ Docker builds successfully

ISSUE #2: Package Name Parsing Bug (Previous Session)
──────────────────────────────────────────────────
Problem:
  - Package names like "git, \" stored as-is (with comma and backslash)
  - Caused invalid package references

Solution:
  - Enhanced _parse_package_line() to strip:

================================================================================
LESSONS LEARNED
================================================================================

1. Template Fallback Depth
   - Always check if Jinja2 is available before calling render_template()
   - Avoid cascading function calls that recurse uncontrollably
   - Use direct generation functions as fallbacks

2. pkg-manifest Design
   - Two-tier idempotency: manifest hash + per-manager inventory checks
   - Manager abstraction: unified interface across apt, pip, brew, conda
   - State tracking: JSON state files prevent duplicate work
   - Pluggable architecture: managers.json + manager shell modules

3. Dockerfile Best Practices
   - Copy files in order of change frequency (least-changing first)
   - Use SHELL directive for bash-specific features
   - Leverage layer caching (unchanged layers reuse previous builds)
   - Test thoroughly before declaring complete
